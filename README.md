Sunset Cover Studio turns your photos and a caption into a GTA 6-style multi-panel poster — pick a layout, crop each panel, choose a Vice City sunset or neon grade, and export a share-ready PNG in 1080×1080, 1080×1350 or 1920×1080. It runs fully offline in the browser; your photos never leave your machine.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
